## §9 送料・配送エリア（V3 改訂）

### 9.1 送料ルール（V2 から継続）
- 本体購入時: 送料無料
- オプションのみ購入時: 一律料金
- 引取り: 無料

### 9.2 配送エリア（V3 強化）
- V3 時点: **北海道のみ販売**
- 注文フォームの「お客様情報」ステップで**都道府県プルダウン**を必須化
- 「北海道」以外を選択した場合、「次へ」ボタンを disabled にし、案内文を表示
- 案内: 「現在は北海道のみ販売しております。本州・四国・九州への販売は順次拡大予定です」
- 将来のエリア拡大は `AVAILABLE_PREFECTURES` 配列の更新で対応

### 9.3 発送スピード
- V2 のまま: 在庫ある商品は 1〜3 営業日以内に発送
- 取付サービス含む場合: 発送 + 取付外注スケジュール調整で**配送後 5〜10 営業日**に取付完了が目安

## §15 保証・アフターサポート（V3 改訂）

### 15.1 保証期間（V2 から継続 + 追加）

| 部品カテゴリ | 保証期間 | 対象 |
|---|---|---|
| ディスプレイ | 1 年 | 製品の通常使用における故障 |
| アンテナ | 1 年 | 同上 |
| モーター | 1 年 | 同上 |
| ケーブル類 | 半年 | ハーネス・配線等 |
| その他部品 | 半年 | ブラケット・ボタン類等 |
| **取付起因不具合（新規）** | **1 ヶ月** | 当社取付サービスに起因する不具合 |

### 15.2 保証起算日（V3 改訂）

| 注文タイプ | 起算日 |
|---|---|
| 取付サービス込み | **取付完了日** |
| 取付サービスなし（本体のみ） | **発送日** |
| 取付完了日が DB に未登録（暫定） | 購入日 + 7 営業日 |

### 15.3 保証適用範囲・対象外（V2 から継続）
- 対象: 通常使用における故障・不具合
- 対象外: 取付不備（自己取付の場合）、改造、水没、落下、経年劣化、消耗品
- 取付起因不具合に該当する場合は、当社取付実施日から 1 ヶ月以内に限り無料で再対応

## §23 取付サービス（新設）

### 23.1 サービス概要
- e-steer 本体の販売価格には**取付サービスが標準で含まれる**
- 対応エリア: 北海道のみ（V3 時点）
- 取付内容:
  - 本体・ブラケットの搬入
  - 物理取付（既存配線への接続を含む）
  - 初期設定・アップデート
  - 試運転（基本動作確認）
- 標準所要時間: 現地 2〜3 時間（移動含む全行程は 1 日換算、場合により一日仕事）

### 23.2 価格構造

- 表示価格 = **取付サービス込み**の税込価格
- 内訳（本体・取付工賃・ブラケット部品・延長ケーブル等）は**非表示**（マージン管理の経営判断による）
- 「取付サービス不要」を選択した場合のみ、割引額を明示

| 商品 | 取付込み（税込） | 取付不要時（税込） | 割引額（税込） |
|---|---:|---:|---:|
| e-steer 20 | ¥1,150,000 | ¥990,000 | -¥160,000 |
| e-steer 20 MAX | ¥1,300,000 | ¥1,100,000 | -¥200,000 |

### 23.3 取付なし（オプトアウト）オプション

- 注文フローのステップ 1（製品選択）または ステップ 2（カート）に「**取付サービス不要（自分で取付する）**」チェックボックスを設置
- チェック時:
  - 該当商品の割引額が小計から減算される
  - 「ブラケット型番は別途お問い合わせください」案内を表示
  - 「自社取付不可によるトラブルは保証対象外です」注意を表示
- データモデル: `selfInstall: boolean`（注文単位、`true` で取付不要）

### 23.4 設置希望日の入力

- 注文フローのステップ 3（お客様情報）に**希望日 3 つ**を date input で入力
- バリデーション:
  - 第 1 希望は必須、第 2・第 3 は任意
  - 過去日付不可
  - 翌日以降〜90 日先まで選択可
- 取付なし注文の場合は希望日入力フィールド非表示
- V3 では空き枠の自動判定は実装しない（手動ディスパッチ）。Phase 2 で外注 GCal 連携時に空き枠フィルタを追加

### 23.5 配車ディスパッチ（V3 では手動）

- 注文確定後、管理画面に「未ディスパッチ注文一覧」を表示
- 運営者（または堀田機工）が外注に手動で「○月○日この客に行ける?」を確認
- 確定したら管理画面で取付担当外注・確定日を入力
- 客には決定後に LINE / メールで通知
- 外注の Google Calendar 自動連携・自動配車は Phase 2 以降

### 23.6 取付当日の品質確保
- 試運転チェックリストの電子化は V3.5 以降
- 客サイン取得・取付完了写真の管理画面アップロードは V3.5 以降

## §24 トラクター機種マスタ自動成長（新設）

### 24.1 概要
- 既存 `machineMaker`（農機メーカー名）・`machineModel`（機種名・型番）フィールドを継続使用
- 注文ごとに入力された機種を**保留マスタ**に蓄積し、管理者が承認したものを**正規マスタ**に昇格
- 正規マスタは次回客の入力時に autocomplete サジェストとして提示（実装は V3.5）

### 24.2 データモデル

#### 保留マスタ（pending_models）
| カラム | 型 | 説明 |
|---|---|---|
| maker | string | 入力されたメーカー名 |
| model | string | 入力された機種名・型番 |
| first_seen_at | timestamp | 初回入力日時 |
| occurrence_count | integer | 同一マスタとして入力された回数 |
| order_ids | string[] | 関連する注文 ID（追跡用） |

#### 正規マスタ（confirmed_models、V3.5 以降）
| カラム | 型 | 説明 |
|---|---|---|
| id | uuid | PK |
| maker_canonical | string | 正規化されたメーカー名 |
| model_canonical | string | 正規化された機種名 |
| aliases | string[] | 入力ゆれの記録（typo 等） |
| bracket_part_no | string | 適合ブラケット型番（運営入力） |
| installation_hours_estimate | number | 取付所要時間目安（運営入力） |
| confirmed_at | timestamp | 正規マスタ昇格日 |

### 24.3 蓄積フロー（Phase 1）
- Webhook で注文確定時、`machineMaker` + `machineModel` を「機種保留マスタ」シート（Google Sheets）に追記
- 同一 (maker, model) ペアが既存にあれば `occurrence_count` をインクリメント
- 同一性判定は完全一致のみ（fuzzy match は Phase 2 以降）

### 24.4 承認フロー（V3.5 以降）
- 管理画面で保留マスタ一覧を閲覧
- 表記ゆれを正規化（例: "クボタ" / "Kubota" / "kubota" を統合）
- 適合ブラケット型番・取付時間目安を入力して正規マスタに昇格

## §25 返送・修理依頼書同梱運用（新設）

### 25.1 概要
- 商品発送時に「**返送・修理依頼書**（A4 1 枚）」を同梱
- 故障時に客がこの紙に記入 → 商品と一緒に箱詰め → 着払いで返送
- 客がオンラインフォームを探さなくて済む物理的なバックアップ

### 25.2 同梱物セット

商品箱に **2 点同梱**:

1. **返送・修理依頼書（A4 1 枚）**
   - 印字済み: 購入番号、お名前、ご住所、ご購入日、取付完了日、保証期間一覧、返送先住所、QR コード（オンライン手続き用 URL）
   - 記入欄: 返送理由、故障部位、症状詳細、変更後連絡先
2. **着払い送り状（1 枚）**
   - 印字済み（お届け先=返送先住所、ご依頼主=客の名前住所、着払いチェック済）
   - 客は箱に貼って持ち込み or 集荷依頼

### 25.3 返送先

```
〒082-0004 北海道河西郡芽室町東芽室北 1 線 20 番 25
NOVA STELLA 内 E-FIX 修理窓口
（同建物内・三菱農機販売株式会社 帯広営業所）
TEL: 080-6282-4834
```

### 25.4 送料

| 区分 | 送料負担 |
|---|---|
| 保証期間内 | **当社負担**（着払い） |
| 保証期間外 | **お客様負担**（元払い） |

### 25.5 配送業者
- **主**: ヤマト運輸（クロネコビジネスメンバーズ契約後 B2 クラウドで伝票発行）
- **副**: 佐川急便（スマートクラブ for business 契約後 e 飛伝Ⅲで伝票発行）
- 両社並行契約することで配送業者の二重化を実現
- V3 着手時点: 両社とも契約申請中。契約成立まではアナログ運用（手書き伝票同梱）で代替

### 25.6 印刷フロー（V3 Phase 1b）

- 管理画面の `/admin/orders/[orderId]/return-slip` ページ
- ブラウザの Ctrl+P で A4 印刷
- 出荷準備時に物理プリンタで印刷 → 商品と同梱

### 25.7 オンライン返送フォーム（V3 Phase 1b）
- 返送依頼書の QR コードから `/return?o=<purchaseNumber>` へ遷移
- 客がスマホからも返送理由・症状を送信可能
- 受信は「Web 返送依頼」シート（Google Sheets）に追記

## §13 特定商取引法に基づく表示（V3 改訂）

V2 から以下を変更:

### 販売価格
- 個別の取付料・ブラケット代・スリーブ等の内訳行を削除
- 取付サービス込みの税込価格のみ表示

```
e-steer 20: ¥1,045,455（税別）/ ¥1,150,000（税込・取付サービス込み）
e-steer 20 MAX: ¥1,181,819（税別）/ ¥1,300,000（税込・取付サービス込み）
取付サービスを利用しない場合: 各 -¥160,000 / -¥200,000 の割引
```

### 商品の引渡し時期
- 「在庫保有のため、原則 1〜3 営業日以内に発送。**取付サービスをご利用の場合は、発送後 5〜10 営業日を目安に取付完了**。在庫切れの場合は入荷後速やかに発送」

### 商品代金以外の必要料金
- 取付サービス料（本体販売価格に含む）
- オプションのみ購入時の送料
- 振込手数料（顧客負担）
- 返送送料（保証期間外）
